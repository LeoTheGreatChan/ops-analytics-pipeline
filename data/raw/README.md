# Raw data

This folder is intentionally empty in the repository. The dataset is a third-party Kaggle dataset and is not redistributed here.

**Source:** [Amazon Delivery Dataset](https://www.kaggle.com/datasets/sujalsuthar/amazon-delivery-dataset) (Kaggle, real-world last-mile delivery data)

**To reproduce the pipeline:**

1. Download the dataset from the link above (free Kaggle account required)
2. Unzip and place `amazon_delivery.csv` in this folder
3. Run the scripts in `/scripts` in order (see main README for the full sequence)

**Dataset summary:** 43,739 rows, delivery records from Feb–Apr 2022, covering agent details, weather, traffic, vehicle type, area, and delivery time. Full column reference in the main README's Data section.
